============================================================
COMPUTER TOOLKIT — RELEASE MANIFEST
============================================================

Purpose:
Portable, safety-first computer diagnosis, data preservation,
recovery, and repair toolkit.

Design principle:
OBSERVE -> PRESERVE -> DIAGNOSE -> CONFIRM -> REPAIR

============================================================

============================================================

01_SYSTEM_INFO
    Windows system and hardware identification.

02_HARDWARE_DIAGNOSTICS
    Storage, memory, GPU, network, battery, and device checks.

    Network troubleshooting and basic diagnostics.

    TestDisk / PhotoRec recovery tools.

    Read-only Windows repair assessment.

06_BACKUP

07_SECURITY_CHECKS
    Read-only security assessment.

08_PORTABLE_TOOLS
    Approved portable diagnostic utilities.

09_DOCUMENTATION
    Safety rules, workflows, guides, checklists, and indexes.

10_SCRIPTS
    Session management, report collection, and toolkit utilities.

SESSIONS
    Per-computer diagnostic session records.

============================================================
SAFETY MODEL
============================================================

GREEN
    Read-only inspection and diagnostics.

YELLOW
    Operations requiring confirmation and care.

RED
    Potentially destructive or security-sensitive operations.

The toolkit does not intentionally provide workflows for:

    Password bypass
    BitLocker bypass
    Administrator bypass
    BIOS/UEFI bypass
    Security-software disabling
    Unauthorized file access
    Unauthorized software installation
    Drive formatting
    Unnecessary partition deletion
    Destructive disk operations

============================================================
PRIMARY WORKFLOW
============================================================

1. Obtain permission.
2. Understand the reported problem.
3. Identify important data.
4. Determine backup status.
5. Identify the operating system.
6. Identify physical storage.
7. Run read-only diagnostics.
8. Record findings.
9. Preserve data if necessary.
10. Confirm the diagnosis.
11. Obtain approval for changes.
12. Perform the smallest justified repair.
13. Verify the result.
14. Document the session.

============================================================
PORTABLE USB STORAGE
============================================================

The USB also contains:

    STORAGE_HUB\PERSONAL
    STORAGE_HUB\DOCUMENTS
    STORAGE_HUB\DOWNLOADS
    STORAGE_HUB\PHOTOS
    STORAGE_HUB\TRANSFER
    STORAGE_HUB\TEMPORARY

The Linux Mint boot environment is separate from the
general-purpose storage organization.

Do not delete or rename Linux Mint boot files.

If Windows asks to format the USB:

    CANCEL.

============================================================
PRIVACY
============================================================

Do not store:

    Passwords
    Authentication codes
    Browser sessions
    Private credentials

Do not copy another person's private files without permission.

Session reports may contain identifying information about
a computer and should be handled appropriately.
