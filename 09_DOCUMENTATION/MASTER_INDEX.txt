============================================================
COMPUTER TOOLKIT — MASTER INDEX
============================================================

PURPOSE
-------
Portable first-aid toolkit for legitimate computer diagnosis,
data preservation, recovery, and repair.

CORE WORKFLOW
-------------
OBSERVE -> PRESERVE -> DIAGNOSE -> CONFIRM -> REPAIR

============================================================

============================================================

Collect basic Windows computer information.

Reports:
Windows version
Computer model
CPU

Storage
GPU
Network adapters
Battery
Device errors

Risk:
GREEN — READ-ONLY

04_FILE_RECOVERY
============================================================

Contains:

TestDisk
PhotoRec
QPhotoRec

Advanced file, partition, and filesystem recovery.

Risk:
YELLOW / RED

============================================================
05_WINDOWS_REPAIR
============================================================

Windows-Repair-Assessment.ps1

Purpose:
Assess Windows system-file/component-store condition.

Initial checks:

DISM /CheckHealth
SFC /verifyonly

Risk:
GREEN — ASSESSMENT ONLY

Repair operations such as:

DISM /RestoreHealth
sfc /scannow

are intentionally NOT automatic.

See:

WINDOWS_REPAIR_DECISION_GUIDE.txt

============================================================
06_BACKUP
============================================================

Safe-FileBackup.ps1

Purpose:
Perform an explicitly confirmed recursive file copy.

Safety:
- source is not deleted
- source is not moved
- destination must be deliberately selected
- user must explicitly confirm

See:

BACKUP_PRESERVATION_GUIDE.txt

Risk:
YELLOW — DATA COPYING

============================================================
SAFETY LEVELS
============================================================

GREEN
------
Read-only inspection.

YELLOW
-------
Potentially changes configuration or copies data.

STOP AND CONFIRM.

RED
---
Potentially destructive.

Do not use casually.

Examples:

Formatting
Partition deletion
Disk overwriting
Filesystem modification
Advanced recovery
Windows reinstallation
Security/access bypass

============================================================
IMPORTANT USB RULE
============================================================

This USB contains the Linux Mint boot environment.

Do NOT:

Format the USB
Delete Linux Mint boot files
Rename Linux Mint boot files
Assume Windows can safely reformat the drive

If Windows asks:

"You need to format the disk before you can use it."

Choose:

CANCEL

============================================================
FINAL PRINCIPLE
============================================================

This toolkit is designed to help preserve computers,
not take control of them.

When uncertain:

STOP.

Record what you see.

Identify the source and destination.

Preserve important data.

Then decide what to do.

OPERATOR CHECKLIST
============================================================

OPERATOR_CHECKLIST.txt

Use this as the practical step-by-step checklist during a
computer assistance session.

Recommended workflow:

OBSERVE
  ->
PRESERVE
  ->
DIAGNOSE
  ->
CONFIRM
  ->
REPAIR
  ->
VERIFY
  ->
DOCUMENT

The checklist is intended to prevent accidental changes,
unnecessary repairs, and loss of important data.
