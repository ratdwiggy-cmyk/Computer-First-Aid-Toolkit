============================================================
COMPUTER TOOLKIT — SYSINTERNALS
============================================================

PURPOSE
-------

The Computer Toolkit can use selected Microsoft Sysinternals
utilities for advanced Windows observation and diagnostics.

The Sysinternals executable files are NOT included in this
GitHub project.

Users should obtain Sysinternals directly from Microsoft.

OFFICIAL SOURCE
---------------

Microsoft Sysinternals:

https://learn.microsoft.com/en-us/sysinternals/downloads/

The official Sysinternals Suite download is available from
Microsoft's Sysinternals website.

APPROVED TOOLS
--------------

The Computer Toolkit's normal diagnostic launcher is designed
to use:

Process Explorer
Autoruns
Process Monitor
TCPView
RAMMap
Sigcheck

These are observation/diagnostic tools and are intentionally
separated from more powerful utilities.

RESTRICTED TOOLS
----------------

Some Sysinternals utilities have powerful administrative,
security, system-modification, or destructive capabilities.

Examples include:

PsExec
PsPasswd
SDelete
Volumeid
Sysmon
NotMyFault

These should not be treated as normal diagnostic tools.

SAFETY
------

Do not use Sysinternals utilities to:

- bypass passwords
- bypass BitLocker
- bypass administrator restrictions
- disable security controls
- circumvent organizational policies
- modify another person's computer without permission

Always determine what a tool will do before executing it.
